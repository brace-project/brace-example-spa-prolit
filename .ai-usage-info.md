# AI Usage Info

## Zweck

`brace-example-spa-prolit` is a reference application for Brace plus a Vite/TypeScript SPA built with TrunkJS Prolit. Backend code lives under `App.be/`, frontend code under `App.fe/`, and `www/index.php` is only the web entrypoint.

## Relevant examples

- `App.be/src/Controller/GreetingController.php` — class-based Brace controller with a `#[BraceRoute]` attribute.
- `App.be/20_routes.php` — controller registration plus `TypeScriptApiStubModule` with automatic generation.
- `App.fe/vite.config.ts` — Vite proxy and `vite-plugin-run` hook for `spa-api-build`.
- `App.fe/src/pages/HomePage.ts` — class-based Prolit page with `@route`, generated API client and `scopeResource`.
- `App.fe/src/AppShell.ts` — Prolit application shell with `<router-content>`.
- `App.fe/src/main.ts` — TrunkJS Router registration and startup.

## Temporary VCS dependencies

Until the reorganized TrunkJS packages are published, `App.fe/package.json` uses pnpm Git subdirectory dependencies from `trunkjs/trunkjs-monorepo`. The matching Vite and TypeScript aliases intentionally resolve the TypeScript source entrypoints. Replace these Git dependencies and aliases with published package versions once available.

## API generation

Do not add a separate PHP build file or a Brace-specific Vite plugin. Configure the output only in `TypeScriptApiStubModule` and use its registered command:

```bash
vendor/bin/brace spa-api-build
```

The generated `App.fe/src/generated-api.ts` is ignored and must not be edited manually.
