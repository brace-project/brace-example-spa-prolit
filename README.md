# Brace + Prolit SPA example

Minimal SPA with a **Brace/PHP API** and a **TrunkJS Prolit** frontend.
Brace serves the SPA; Vite provides the frontend development server and builds.

## Directory map

```text
.
├── bootstrap.php                     # Shared CLI/web bootstrap
├── composer.json                      # PHP dependencies and PSR-4 mapping
├── package.json                       # Frontend dependencies and scripts
├── tsconfig.json                      # TypeScript configuration
├── vite.config.ts                     # Development server and build
├── app.be/                            # Brace backend
│   ├── 01_init.php                    # App environment and modules
│   ├── 10_middleware.php              # SPA shell and asset serving
│   ├── 20_routes.php                  # API routes and stub generation
│   └── src/
│       └── Ctrl/                      # HTTP controllers
│           ├── GreetingCtrl.php       # GET greeting API
│           ├── CalculateCtrl.php      # Typed POST calculation API
│           ├── AnyCtrl.php            # Untyped array POST API
│           └── Dto/                   # Controller request/response DTOs
│               ├── GreetingResponse.php
│               ├── CalculateResponse.php
│               └── CalculateRequest.php
├── app.fe/                            # Prolit frontend
│   ├── src/
│   │   ├── main.ts                    # Register elements and start router
│   │   ├── app.scss                   # Nextstrap stylesheet imports
│   │   ├── generated-api.ts           # Generated; never edit
│   │   ├── pages/                     # Routable Web Components
│   │   │   ├── HomePage/
│   │   │   │   └── HomePage.ts
│   │   │   └── FormExamplePage/
│   │   │       ├── FormExamplePage.ts
│   │   │       └── dialogs/           # Page-local dialogs
│   │   │           └── FormExampleDialog.ts
│   │   ├── dialogs/                   # Shared dialogs
│   │   │   └── SettingsDialog.ts      # Typed POST example
│   │   └── elements/                  # Reusable Web Components
│   │       └── CalculateDemoElement.ts # Async POST example
│   └── dist/                           # Production build output
└── www/
    └── index.php                      # Apache front controller
```

Small pages can be a single file under `pages/`. For larger pages,
colocate page-only dialogs/elements under
`pages/<PageName>/dialogs/` and `pages/<PageName>/elements/`;
shared components go into top-level `dialogs/` or `elements/`.
Folder names are lowercase plurals; component classes use PascalCase.

## Quick start

```bash
composer install
pnpm install
pnpm dev
```

Open `http://localhost:4000/` with Apache/PHP available on port 80.
Vite serves frontend source files and forwards application/API requests to Brace.
For production, run `pnpm build` and serve `app.fe/dist/` through Apache
with `DEV_MODE=0` (Vite is not needed at runtime).

**Details:** [Development, Vite, SPA-Serve and production build](docs/DEVELOPMENT.md).

## Examples

| Example | Frontend | Backend |
|---|---|---|
| Greeting (GET) | `pages/HomePage/HomePage.ts` | `GreetingCtrl::get` → `Demo.Greeting` |
| Calculation (POST) | `elements/CalculateDemoElement.ts` | `CalculateCtrl::post` → `Demo.Calculate` |
| Calculation settings | `dialogs/SettingsDialog.ts` | `CalculateCtrl::post` → `Demo.Calculate` |
| Untyped array (POST) | `dialogs/SettingsDialog.ts` | `AnyCtrl::post` → `Demo.Any` |
| Form, NTE Data Table and NTE Stepper | `pages/FormExamplePage/` | Client-side Prolit |

`CalculateCtrl` demonstrates typed `CalculateRequest` and
`CalculateResponse` DTOs. `AnyCtrl` accepts and returns a plain PHP
`array`; its element types are **not** part of the TypeScript API contract.
For a specific request/response structure, create a DTO.

The frontend imports the generated API client from
`app.fe/src/generated-api.ts`. Do not edit this file manually:
the backend routes and DTOs are its source of truth.

## Nextstrap components

The frontend uses **Nextstrap Style Base**, Buttons, Elements, Switch,
Utils and the NTE Input, NTE Data Table and NTE Stepper Web Components.
`app.fe/src/app.scss` imports their default styles without custom
application-wide selectors. Layout is expressed via Nextstrap utility
classes and occasional inline styles in the templates.

The form example demonstrates live `nte-input` bindings, editing
`nte-data-table` rows and a clickable `nte-stepper` showing current
input, table and event output. The home page includes a theme switch.
